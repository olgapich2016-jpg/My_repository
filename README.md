[2. Add Two Numbers] https://leetcode.com/problems/add-two-numbers/description/
Medium
Алгоритм складывает цифры пошагово, учитывая перенос (переменная tr), не пытаясь преобразовывать числа в целые значения.
Сначала создаётся вспомогательный узел dummy с нулевым значением. Этот узел не входит в результат напрямую, он является «отправной точкой» для построения списка, tail указывает на текущий последний узел результирующего списка, чтобы можно было добавлять новые узлы в конце. На первой шаге tail указывает на dummy.
Далее выполняется проход по обоим спискам l1 и l2 по очереди, в каждом узле берутся цифры (если узла нет — то 0) и прибавляется перенос (переменная tr). Создается новый узел с суммой mod 10 и обновляется перенос как sum / 10. Данный цикл продолжается до тех пор, пока оба списка не дойдут до 0 и перенос станет 0. В результате, возвращается головной узел результата.

[5. Longest Palindromic Substring] https://leetcode.com/problems/longest-palindromic-substring/
Medium
В начале алгоритма выполняется проверка, если строка пустая или состоит из одного символа, она сама является палиндром, также выполняется проверка - является ли вся строка палиндромом, если да — она сразу возвращается.
Каждый палиндром имеет центр, алгоритм строится на расширении с центра, пока символы слева и справа совпадают, повтор выполняется для всех центров. 
Переменная start хранит индекс начала найденного на данный момент самого длинного палиндрома, maxLen — его длина, изначально палиндром длиной 1 (одного символа) является минимальным результатом.
Цикл for (строка "for (int center = 0; center < n; ++center)") - главный цикл по всем возможным центрам палиндрома, далее у каждого центра происходит расширение вправо и влево для поиска четных или нечетных палиндромов.
Для поиска нечетного палиндрома: l и r инициализируются текущим центром, пока границы допустимы и символы на левой и правой позициях совпадают, палиндром растягивается, переменная len вычисляет текущую длину палиндрома. Если найден более длинный палиндром, сохраняется его начало и длина, затем границы сдвигатся: l-- и r++.

[46. Permutations] https://leetcode.com/problems/permutations/
Medium
Так как задача имеет ограничение размера массива (до 6, перебор все вариантов не занимает много времени) был выбран итеративный подход с использованием next_permutation. Выполняется объявление переменной N типа вектор векторов целых, в неё будут собираться все полученные перестановки.
Начало цикла do-while - внутри добавляется текущая перестановка в результат перед тем, как перейти к следующей.
Строка "res.push_back(nums);" добавляет текущую последовательность nums в список всех перестановок. После этого next_permutation последовательно генерирует все последующие перестановки до последней, цикл выполняется пока есть следующая перестановка, когда достигается последний вариант перестановки, next_permutation возвраается false и цикл заканчивается.
Время выполнения - примерно O(n! • n) из-за n! перестановок и копирования n элементов на каждую, где n = nums.length (до 6). Память - O(n!) для результата.
